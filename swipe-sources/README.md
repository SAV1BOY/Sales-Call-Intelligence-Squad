# Swipe Sources — Sales Call Intelligence Squad

> Fontes originais de referência que alimentam a curadoria de swipe files do squad.

## O que são Swipe Sources?

Swipe sources são as fontes primárias de conhecimento — livros, cursos, workshops, gravações e benchmarks — que fundamentam os frameworks, checklists e best practices usados pelo squad. Diferem dos swipe files (em `swipe/`), que são exemplos curados de outputs reais do squad.

## Estrutura

| Arquivo | Conteúdo |
|---------|----------|
| `books-and-courses.md` | Livros, cursos e workshops que fundamentam o squad |
| `call-recordings-index.md` | Índice de gravações originais usadas como referência |
| `industry-benchmarks.md` | Fontes de benchmarks de mercado (Gong, Chorus, HubSpot, etc.) |

## Relação com Outros Diretórios

- `reference/` — Material de referência processado e organizado por tema
- `authority/` — Resumos dos 11 especialistas e suas metodologias
- `frameworks/` — Frameworks operacionais derivados dessas fontes
- `swipe/` — Exemplos curados de outputs do squad (best calls, best rewrites, etc.)
