# Cole Gordon — Índice de Conteúdo

> Índice curado de conteúdos de Cole Gordon relevantes para o Squad: processo de fechamento, treinamento de closers e construção de times de vendas high ticket.

## Tipo de Conteúdo
Vídeos no YouTube, programas de treinamento, podcasts, conteúdo da 8-Figure Agency

## Conteúdos Relevantes

### Closers.io Training Program
- **Título**: Programa de Treinamento Closers.io
- **Tipo**: Curso / programa de treinamento
- **Conceitos-chave**: Processo de fechamento em 5 etapas, tonalidade consultiva, isolamento de objeções, assumptive close
- **Aplicação no Squad**: Base do processo de fechamento usado no scorecard. As etapas do programa são referência para avaliação de competência.

### How to Handle ANY Objection (YouTube)
- **Título**: The ONLY Objection Handling Framework You Need
- **Tipo**: Vídeo YouTube
- **Conceitos-chave**: Framework de 4 passos para objeção (acknowledge, isolate, address, close), looping technique
- **Aplicação no Squad**: Framework primário para o bloco de objeção no scorecard. Closers são treinados neste modelo como base.

### Discovery Call Masterclass (YouTube)
- **Título**: How to Run a Perfect Discovery Call
- **Tipo**: Vídeo YouTube
- **Conceitos-chave**: Perguntas de situação, transição para dor, quantificação, comprometimento emocional
- **Aplicação no Squad**: Referência para construção do bloco de discovery. Complementa o SPIN com abordagem mais direta.

### Sales Tonality Training (YouTube)
- **Título**: How to Use Tonality to Close More Deals
- **Tipo**: Vídeo YouTube
- **Conceitos-chave**: Tons de curiosidade, certeza, empatia e autoridade. Quando usar cada tom na call
- **Aplicação no Squad**: Material de suporte para coaching de tonalidade. Closers assistem como parte do onboarding.

### Building a Remote Sales Team (YouTube)
- **Título**: How I Built an 8-Figure Sales Team from Scratch
- **Tipo**: Vídeo YouTube
- **Conceitos-chave**: Recrutamento de closers, KPIs de performance, coaching contínuo, cultura de vendas
- **Aplicação no Squad**: Referência para gestão do squad e definição de KPIs. O modelo de coaching contínuo é adaptado ao nosso contexto.

### The Follow-Up Framework (YouTube)
- **Título**: How to Follow Up Without Being Annoying
- **Tipo**: Vídeo YouTube
- **Conceitos-chave**: Sequência de follow-up em 7 dias, mensagens de valor, timing ideal, quando desistir
- **Aplicação no Squad**: Base para o processo de follow-up pós-call. Closers seguem esta sequência adaptada.

### Podcast Appearances
- **Título**: Participações em podcasts (Andy Frisella, Ed Mylett, etc.)
- **Tipo**: Podcast
- **Conceitos-chave**: Mindset de closer, resiliência, rotina de alta performance, gestão emocional
- **Aplicação no Squad**: Material motivacional e de mindset para closers em queda de performance.

## Como Usar Este Índice
1. Novos closers devem começar pelo Closers.io Training e Discovery Call Masterclass
2. Closers intermediários focam em Objection Handling e Tonality
3. Closers avançados estudam Building a Remote Sales Team para mentalidade de liderança
4. Use como referência em sessões de coaching para recomendar conteúdo específico
