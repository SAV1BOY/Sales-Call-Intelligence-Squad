# Jeremy Miner — Índice de Conteúdo

> Índice curado de conteúdos de Jeremy Miner relevantes para o Squad: NEPQ (Neuro-Emotional Persuasion Questions), vendas por perguntas e psicologia de decisão.

## Tipo de Conteúdo
Masterclass, vídeos no YouTube, programa 7th Level, podcasts

## Conteúdos Relevantes

### NEPQ Masterclass
- **Título**: Neuro-Emotional Persuasion Questions — Masterclass Completa
- **Tipo**: Curso / masterclass
- **Conceitos-chave**: Perguntas de conexão, perguntas de situação, perguntas de problema-awareness, perguntas de solução-awareness, perguntas de consequência
- **Aplicação no Squad**: Framework complementar ao SPIN para discovery. As perguntas de consequência são usadas para aprofundar camadas de dor.

### 7th Level Communication
- **Título**: Programa 7th Level — Sales Communication System
- **Tipo**: Programa de treinamento
- **Conceitos-chave**: 7 níveis de comunicação em vendas, do nível 1 (informar) ao nível 7 (influenciar), transição de vendedor para consultor
- **Aplicação no Squad**: Modelo de maturidade para closers. Os níveis são referência para a engine de closer maturity.

### Tonality Secrets (YouTube)
- **Título**: How Your Tone of Voice Controls the Sale
- **Tipo**: Vídeo YouTube
- **Conceitos-chave**: Tom de curiosidade genuína, tom de preocupação, tom de desapego, como evitar tom de vendedor
- **Aplicação no Squad**: Complemento ao treinamento de tonalidade. O tom de curiosidade genuína é treinado em todas as sessões de roleplay.

### Why Traditional Selling is Dead (YouTube)
- **Título**: Stop Selling the Old Way — It Doesn't Work Anymore
- **Tipo**: Vídeo YouTube
- **Conceitos-chave**: Morte do pitch de pressão, ascensão da venda consultiva, por que leads odeiam vendedores tradicionais
- **Aplicação no Squad**: Material de mindset para closers que ainda usam abordagem de pressão. Ajuda na transição para venda consultiva.

### Asking vs Telling (YouTube)
- **Título**: Stop Telling and Start Asking — The Key to High-Ticket Sales
- **Tipo**: Vídeo YouTube
- **Conceitos-chave**: Ratio perguntas/afirmações, como fazer o lead vender pra si mesmo, perguntas que geram auto-persuasão
- **Aplicação no Squad**: Fundamento para a engine de talk ratio. Closers devem perguntar mais que afirmar durante discovery.

### Cold Calling with NEPQ (YouTube)
- **Título**: How to Cold Call Using NEPQ
- **Tipo**: Vídeo YouTube
- **Conceitos-chave**: Abertura com pergunta de permissão, neutralização de resistência inicial, transição para discovery
- **Aplicação no Squad**: Adaptável para abertura de calls onde o lead está frio ou não lembra que agendou.

### Sales Podcast com Jeremy Miner
- **Título**: Participações em podcasts de vendas
- **Tipo**: Podcast
- **Conceitos-chave**: Psicologia por trás da decisão de compra, como o cérebro processa preço, gatilhos emocionais em vendas
- **Aplicação no Squad**: Material avançado para closers que querem entender o porquê por trás das técnicas.

## Como Usar Este Índice
1. Comece pela NEPQ Masterclass para fundamento teórico
2. Use os vídeos de Tonality e Asking vs Telling para prática diária
3. Estude Cold Calling com NEPQ para melhorar aberturas de calls frias
4. Consulte 7th Level para avaliar nível de maturidade dos closers
