# Guia de Seleção de Framework

> Qual framework usar em qual fase e situação. Árvore de decisão para escolher a técnica mais eficaz em cada momento da call.

## Princípio de Seleção

Não existe um framework universalmente superior. A escolha depende de 4 fatores: fase da call, perfil do prospect, tipo de objeção e nível de consciência do lead. Este guia fornece a árvore de decisão para cada cenário.

## Árvore de Decisão por Fase

### Rapport — Qual framework usar?

**Se o prospect é corporativo (B2B):**
→ Frame Setting (Cole Gordon): definir agenda e autoridade profissional
→ Doctor Frame (Dan Lok): posicionar-se como diagnosticador

**Se o prospect é empreendedor individual:**
→ Rapport Natural + Tonalidade (Belfort): criar conexão informal com autoridade
→ Belief Alignment (Eli Wilde): identificar crenças compartilhadas

### Discovery — Qual framework usar?

**Se o prospect já sabe o que quer (alta consciência):**
→ SPIN rápido (Rackham): Situation e Problem breves, foco em Implication e Need-payoff
→ Qualification Questions (Dan Lok): verificar fit rapidamente

**Se o prospect não tem clareza do problema (baixa consciência):**
→ NEPQ completo (Miner): percorrer todas as etapas sem pressa
→ Consequence Questions profundas: 4+ camadas de aprofundamento

**Se o prospect é analítico e cético:**
→ Challenger Insight (Dixon & Adamson): ensinar algo novo antes de perguntar
→ SPIN com dados: usar implicações quantificáveis

**Se o prospect é emocional e urgente:**
→ NEPQ focado em dor (Miner): amplificar consequências emocionais
→ Belief Shift (Eli Wilde): trabalhar identidade e estado emocional

### Pitch — Qual framework usar?

**Se o ticket é acima de R$ 30k:**
→ Grand Slam Offer (Hormozi): construir oferta irrecusável com value equation
→ Godfather Offer (Suby): value stack massivo com risk reversal completo

**Se o ticket é entre R$ 5k e R$ 30k:**
→ Value Equation (Hormozi): focar em resultado/esforço/tempo
→ Ponte Discovery-Solução (Cole Gordon): conectar dores com solução

**Se o prospect precisa de justificativa racional:**
→ Challenger (Dixon & Adamson): ensinar, personalizar, assumir controle
→ ROI Calculator: quantificar retorno esperado

### Objeções — Qual framework usar?

**"Preciso pensar":**
→ Isolation (Cole Gordon): isolar a objeção real por trás da cortina
→ Looping (Belfort): voltar ao ponto de certeza mais baixo

**"Está caro":**
→ Value Reframe (Hormozi): reposicionar preço vs. custo da inação
→ Godfather Offer ajuste (Suby): adicionar bônus ou risk reversal

**"Preciso falar com meu sócio/esposa":**
→ Prevenção (Bradley Lea): deveria ter sido resolvido na qualificação
→ Urgência real: criar razão genuína para decisão imediata

**"Já tentei algo parecido":**
→ Belief Shift (Eli Wilde): mudar a crença sobre o que é possível
→ Challenger Insight: mostrar por que as tentativas anteriores falharam

### Closing — Qual framework usar?

**Se objeções foram resolvidas e rapport está alto:**
→ Assumptive Close: agir como se já estivesse decidido
→ CLOSER - Reinforce (Hormozi): reforçar decisão

**Se prospect está indeciso mas não tem objeções claras:**
→ Straight Line (Belfort): medir certeza e trabalhar o ponto mais baixo
→ Urgência genuína: deadline real ou escassez verdadeira

**Se prospect é impulsivo:**
→ Direct Close: pedir diretamente
→ Alternative Close: "começamos segunda ou quarta?"

## Combinações Avançadas

Os melhores closers combinam frameworks. Exemplos eficazes:
- NEPQ (discovery) + Value Equation (pitch) + Isolation (objeções) + Assumptive (close)
- SPIN (discovery) + Challenger (pitch) + Looping (objeções) + Straight Line (close)
- Doctor Frame (rapport) + NEPQ (discovery) + Grand Slam (pitch) + Preventive (objeções)

## Anti-Padrões — Combinações que NÃO Funcionam

- NEPQ (zero pressure) + Urgência artificial = contradição de postura
- Doctor Frame (autoridade) + Desconto imediato = destrói autoridade
- Challenger (ensinar) + Perguntas superficiais = perde credibilidade
