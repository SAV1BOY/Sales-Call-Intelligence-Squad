# Rubrica de Qualidade da Call

> Utilitário que define os critérios de qualidade para cada bloco avaliado no scorecard de calls de vendas.

## Função
Padronizar a avaliação de qualidade de cada bloco da call com critérios objetivos e exemplos de cada nível.

## Bloco 1 — Abertura (Peso: 10%)
| Faixa | Critérios |
|-------|-----------|
| 0-30 | Sem pauta, sem rapport, leitura robótica de script ou submissão |
| 31-50 | Pauta vaga, rapport artificial ou small talk excessivo |
| 51-70 | Pauta definida, rapport funcional, mas sem controle claro |
| 71-85 | Pauta clara em 60s, rapport contextualizado, controle assumido |
| 86-100 | Abertura impecável: rapport natural, pauta, expectativa e permissão para perguntas |

## Bloco 2 — Discovery (Peso: 25%)
| Faixa | Critérios |
|-------|-----------|
| 0-30 | Perguntas de checklist, sem profundidade, talk ratio closer >60% |
| 31-50 | Algumas perguntas abertas mas sem follow-up, 1-2 camadas de dor |
| 51-70 | Perguntas de aprofundamento presentes, 2-3 camadas, talk ratio 45-55% |
| 71-85 | SPIN/NEPQ aplicado, 3+ camadas, quantificação, talk ratio <45% |
| 86-100 | Discovery exemplar: 4+ camadas, quantificação emocional e financeira, lead emocionalmente comprometido |

## Bloco 3 — Pitch (Peso: 15%)
| Faixa | Critérios |
|-------|-----------|
| 0-30 | Pitch genérico, monólogo de features, sem conexão com discovery |
| 31-50 | Alguma personalização mas ainda focado em features, sem cases |
| 51-70 | Conectado à dor do lead, cases presentes mas genéricos |
| 71-85 | Personalizado com linguagem do lead, cases segmentados, micro-commits |
| 86-100 | Pitch segmentado, cases do nicho exato, lead confirma valor em cada bloco |

## Bloco 4 — Price Reveal (Peso: 15%)
| Faixa | Critérios |
|-------|-----------|
| 0-30 | Preço solto sem contexto, hesitação, pedido de permissão |
| 31-50 | Alguma ancoragem mas fraca, sem value stack ou risk reversal |
| 51-70 | Ancoragem presente, value stack parcial, confiança moderada |
| 71-85 | Ancoragem forte, value stack completo, risk reversal, naturalidade |
| 86-100 | Ancoragem impecável, value stack de 4+ itens, risk reversal com prova, transição fluida |

## Bloco 5 — Objeção (Peso: 20%)
| Faixa | Critérios |
|-------|-----------|
| 0-30 | Pressão, evasão, argumentação contra o lead ou passividade total |
| 31-50 | Tentativa de tratamento mas sem isolamento ou com script genérico |
| 51-70 | Isolamento básico, resolução parcial, sem confirmação |
| 71-85 | Isolamento preciso, looping de dor, resolução com evidência, confirmação |
| 86-100 | Tratamento magistral: isolamento + looping + belief shift + confirmação + avanço fluido |

## Bloco 6 — Fechamento (Peso: 15%)
| Faixa | Critérios |
|-------|-----------|
| 0-30 | Sem pergunta de fechamento, "o que você acha?", limbo sem next step |
| 31-50 | Tentativa de fechar mas com hesitação ou pressão artificial |
| 51-70 | Assumptive close básico, next step definido mas sem data/hora |
| 71-85 | Assumptive close confiante, next step com data e hora, transição fluida |
| 86-100 | Fechamento perfeito: natural, confiante, next step travado bilateral, onboarding agendado |

## Integração
- Usado pelos avaliadores de call como referência de avaliação
- Usado no **scorecard-engine** como base de critérios por bloco
- Usado em sessões de coaching para mostrar ao closer onde ele está e onde pode chegar
