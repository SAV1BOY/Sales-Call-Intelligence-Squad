# Fase 3 — Criação de Playbook

> Transformar os padrões extraídos em um playbook acionável para o time de closers.

## Objetivo
Criar um documento prático que qualquer closer possa usar como guia para replicar os comportamentos que levam a calls ganhas.

## Inputs
- Padrões de sucesso (output da Fase 2)
- Perfil da call ganha ideal
- Exemplos de transcrições reais

## Atividades
1. Estruturar o playbook por fase da call: o que fazer em cada etapa
2. Incluir o framework recomendado para cada fase com justificativa baseada nos dados
3. Adicionar scripts de referência extraídos das calls ganhas (anonimizados)
4. Incluir checklist de "sinais de que está no caminho certo" por etapa
5. Incluir checklist de "red flags" que indicam que a call está saindo do padrão
6. Adicionar seção de anti-padrões com exemplos do que evitar
7. Criar versão resumida (1 página) para consulta rápida antes da call
8. Criar versão completa com todos os detalhes para estudo aprofundado

## Agentes Responsáveis
- Report Generator (responsável principal)
- Script Suggester (suporte para scripts)

## Output
- Playbook completo baseado em padrões de sucesso
- Versão resumida de 1 página para consulta rápida
- Checklists por etapa incluídos
- Scripts de referência anonimizados

## Critérios de Conclusão
- [ ] Playbook completo criado
- [ ] Versão resumida de 1 página pronta
- [ ] Scripts de referência incluídos
- [ ] Revisado por pelo menos 2 closers para validação de naturalidade
