# Fase 0 — Seleção de Calls Ganhas

> Selecionar uma amostra representativa de calls ganhas para análise de padrões de sucesso.

## Objetivo
Criar uma amostra de alta qualidade de calls ganhas que permita identificar o que os melhores closers fazem de diferente.

## Inputs
- Registry com histórico de calls dos últimos 90 dias
- Dados de resultado: calls ganhas com ticket e closer identificados
- Mínimo de 30 calls ganhas disponíveis

## Atividades
1. Filtrar todas as calls ganhas dos últimos 90 dias
2. Selecionar 25-30 calls com diversidade de: closers, tickets, nichos e tipos de lead
3. Priorizar calls com tickets acima da média (indicam performance premium)
4. Incluir calls de pelo menos 3 closers diferentes para evitar viés individual
5. Verificar que as transcrições estão disponíveis e em qualidade adequada
6. Registrar metadados de cada call selecionada: closer, ticket, nicho, data, duração
7. Classificar calls por "nível de dificuldade": lead quente vs. frio, objeções enfrentadas, complexidade

## Agentes Responsáveis
- Registry Manager (responsável principal)
- Intake Agent (validação de qualidade das transcrições)

## Output
- Lista de 25-30 calls ganhas selecionadas com metadados
- Classificação por nível de dificuldade
- Transcrições validadas e prontas para auditoria

## Critérios de Conclusão
- [ ] 25-30 calls selecionadas com critérios de diversidade
- [ ] Metadados completos para cada call
- [ ] Transcrições validadas
- [ ] Classificação de dificuldade feita

## Notas de Execução

- Evitar selecionar apenas calls fáceis — incluir calls desafiadoras para encontrar padrões que funcionam sob pressão
- Calls com turnaround (parecia perdida e virou) são especialmente valiosas para análise
