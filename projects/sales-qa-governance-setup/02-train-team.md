# Fase 2 — Treinamento do Time

> Treinar auditores e gestores no programa de QA, scorecards e processos de feedback.

## Objetivo
Garantir que todos os envolvidos no programa de QA estejam alinhados nos critérios, processos e ferramentas.

## Inputs
- Standards documentados (output da Fase 0)
- Scorecards finalizados (output da Fase 1)
- Lista de auditores e gestores que participarão do programa

## Atividades
1. Realizar Workshop de Auditoria de Calls (4 horas) para todos os auditores
2. Realizar sessão de calibração inicial com 3 calls de referência
3. Treinar gestores no uso dos dados de QA para coaching (2 horas)
4. Treinar closers no que será avaliado e como funciona o feedback (1 hora)
5. Distribuir scorecards e guias de preenchimento para todos os auditores
6. Realizar rodada piloto: cada auditor faz 3 auditorias com supervisão
7. Revisar as auditorias piloto, dar feedback aos auditores e ajustar processo
8. Definir responsáveis e backup para cada grupo de closers
9. Documentar dúvidas frequentes dos treinamentos e criar seção de FAQ específica

## Agentes Responsáveis
- Exercise Designer (responsável pelo treinamento)
- Calibration Agent (sessão de calibração)
- Quality Checker (revisão das auditorias piloto)

## Output
- Auditores treinados e calibrados
- Gestores treinados no uso dos dados
- Closers informados sobre o programa
- Auditorias piloto revisadas e aprovadas
- FAQ de treinamento documentado

## Critérios de Conclusão
- [ ] Workshop realizado com todos os auditores
- [ ] Calibração inicial concluída (variação menor que 5 pontos)
- [ ] Gestores treinados
- [ ] Closers informados
- [ ] Auditorias piloto aprovadas
