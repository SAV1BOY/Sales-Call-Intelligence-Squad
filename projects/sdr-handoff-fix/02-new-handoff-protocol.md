# Fase 2 — Novo Protocolo de Handoff

> Desenhar e implementar um novo processo de transição SDR→closer que resolva os gaps identificados.

## Objetivo
Criar um protocolo padronizado que garanta que toda informação relevante chegue ao closer antes da call, com expectativas alinhadas.

## Inputs
- Lista priorizada de gaps (output da Fase 1)
- Feedback de closers e SDRs sobre o que precisam
- Melhores práticas de handoff do mercado

## Atividades
1. Criar checklist obrigatório que o SDR deve preencher antes de agendar call com closer
2. Definir campos mínimos: nome, empresa, dor principal, decisor confirmado, budget aproximado, urgência, expectativas
3. Criar template de briefing que o SDR envia ao closer 24h antes da call
4. Definir protocolo de alinhamento de expectativas: o que o SDR pode e não pode prometer
5. Criar script de abertura para o closer que referencia informações do briefing
6. Configurar CRM/sistema para suportar os novos campos e fluxo
7. Treinar SDRs no novo protocolo (sessão de 2 horas)
8. Treinar closers no uso do briefing (sessão de 1 hora)
9. Definir SLA: briefing deve chegar 24h antes da call, com penalidade se não chegar

## Agentes Responsáveis
- Integration Agent (responsável principal)
- Script Suggester (scripts de abertura)
- Exercise Designer (treinamento)

## Output
- Checklist de qualificação obrigatório para SDR
- Template de briefing padronizado
- Scripts de abertura para closer
- SDRs e closers treinados
- Protocolo documentado e publicado

## Critérios de Conclusão
- [ ] Checklist e template criados
- [ ] Protocolo documentado
- [ ] CRM configurado
- [ ] SDRs treinados
- [ ] Closers treinados
- [ ] SLA definido
