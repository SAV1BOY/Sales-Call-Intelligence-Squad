# Fase 3 — Estratégia de Recuperação

> Desenhar abordagem personalizada de re-engajamento para cada deal prioritário.

## Objetivo
Criar scripts e estratégias de re-engajamento que abordem especificamente o motivo da perda original de cada deal.

## Inputs
- Top 10 deals para re-engajamento (output da Fase 2)
- Diagnóstico de causa raiz de cada deal
- Informações específicas extraídas das auditorias
- Reescritas dos momentos-chave

## Atividades
1. Para cada deal, criar mensagem de re-engajamento personalizada (não genérica)
2. A mensagem deve endereçar indiretamente o motivo da perda sem mencionar a call anterior negativamente
3. Definir canal de abordagem: mensagem, ligação, email (baseado no que melhor funcionou com esse prospect)
4. Definir timing: melhor dia e horário para re-engajamento
5. Preparar script para a nova call que evita os erros identificados na auditoria
6. Decidir se o closer será o mesmo ou outro (se o erro foi do closer, considerar trocar)
7. Se a objeção original foi preço: preparar nova ancoragem ou oferta ajustada
8. Se foi timing: validar se o timing agora é melhor e usar isso como gancho
9. Treinar o closer designado na estratégia específica de cada deal

## Agentes Responsáveis
- Script Suggester (responsável principal)
- Coaching Plan Builder (treinamento do closer)

## Output
- 10 estratégias de re-engajamento personalizadas
- Mensagens de abordagem escritas e revisadas
- Scripts para nova call preparados
- Closers designados e treinados

## Critérios de Conclusão
- [ ] Estratégia definida para cada deal
- [ ] Mensagens escritas e aprovadas
- [ ] Scripts preparados
- [ ] Closers treinados
