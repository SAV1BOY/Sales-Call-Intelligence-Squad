# Fase 1 — Auditoria das Calls Perdidas

> Auditar as calls dos deals perdidos para identificar exatamente o que deu errado e onde houve oportunidade desperdiçada.

## Objetivo
Entender a causa raiz da perda de cada deal com precisão suficiente para desenhar uma estratégia de re-engajamento personalizada.

## Inputs
- Top 20 deals para recuperação (output da Fase 0)
- Transcrições das calls originais
- Metadados de cada deal

## Atividades
1. Executar auditoria completa (9 fases) para cada uma das 20 calls
2. Foco especial: identificar o momento exato onde a call se perdeu
3. Classificar o motivo real da perda (pode diferir do motivo declarado pelo prospect)
4. Identificar oportunidades perdidas: momentos onde o closer poderia ter feito diferente
5. Gerar reescritas dos momentos-chave para cada call
6. Classificar deals por tipo de erro: erro de discovery, erro de pricing, erro de objeção, erro de close
7. Identificar quais deals tiveram objeções não resolvidas (oportunidade de resolver no re-engajamento)
8. Registrar informações específicas que podem ser usadas na abordagem de recuperação

## Agentes Responsáveis
- Todos os agentes do pipeline de auditoria
- Win/Loss Correlator (foco em causas de perda)

## Output
- 20 auditorias completas com diagnóstico de perda
- Momento de ruptura identificado em cada call
- Motivo real vs. motivo declarado comparados
- Reescritas dos momentos-chave
- Informações para re-engajamento extraídas

## Critérios de Conclusão
- [ ] 20 calls auditadas
- [ ] Momento de ruptura identificado em cada uma
- [ ] Motivo real classificado
- [ ] Informações para re-engajamento documentadas
