# Fase 0 — Auditoria de 50 Calls

> Auditar 50 calls para coletar amostra representativa de objeções levantadas por prospects.

## Objetivo
Construir uma base de dados com todas as objeções identificadas em 50 calls para análise sistemática e construção da biblioteca de respostas.

## Inputs
- 50 transcrições de calls dos últimos 60 dias
- Mix recomendado: 25 calls perdidas, 15 ganhas, 10 reagendadas
- Múltiplos closers representados (mínimo 3)
- Diferentes tickets e nichos quando possível

## Atividades
1. Executar auditoria focada em objeções para cada uma das 50 calls (não precisa ser auditoria completa — foco no bloco de objeções)
2. Para cada call, registrar: objeção verbalizada, momento da call, contexto, resposta do closer, resultado da resolução
3. Registrar também objeções não verbalizadas mas detectadas pelo comportamento do prospect
4. Classificar o resultado de cada tentativa de resolução: resolvida, parcialmente resolvida, não resolvida
5. Anotar o framework usado pelo closer na resolução (se identificável)
6. Calcular estatísticas: total de objeções, média por call, distribuição por fase da call
7. Criar planilha com todas as objeções coletadas para análise na próxima fase

## Agentes Responsáveis
- Objection Mapper (responsável principal)
- Framework Detector (suporte para identificar frameworks na resolução)

## Output
- Planilha com todas as objeções coletadas (estimativa: 150-250 objeções)
- Estatísticas gerais: frequência, distribuição, taxa de resolução
- Anotações sobre contexto de cada objeção

## Critérios de Conclusão
- [ ] 50 calls auditadas com foco em objeções
- [ ] Todas as objeções registradas com contexto
- [ ] Resultado de cada resolução classificado
- [ ] Planilha consolidada pronta para análise
