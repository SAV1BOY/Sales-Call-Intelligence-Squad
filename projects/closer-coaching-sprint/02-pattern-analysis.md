# Fase 2 — Análise de Padrões

> Identificar padrões recorrentes nas 5 auditorias que revelam os gaps sistêmicos do closer.

## Objetivo
Distinguir problemas pontuais de padrões recorrentes e identificar as causas raiz sistêmicas que mais impactam a performance.

## Inputs
- 5 auditorias completas com scorecards (output da Fase 1)
- Tabela consolidada de scores por bloco
- Reescritas das 5 calls
- Histórico do closer no registry

## Atividades
1. Analisar os 3 blocos mais fracos: verificar se a fraqueza é consistente em todas as 5 calls
2. Para cada fraqueza consistente, identificar o comportamento específico que se repete
3. Mapear cadeias causais: comportamento repetido → causa raiz → framework corretor
4. Identificar correlações entre blocos (ex: discovery rasa sempre leva a objeções de preço)
5. Comparar calls ganhas vs. perdidas: qual bloco faz a diferença entre ganhar e perder?
6. Verificar se a auto-avaliação do closer (Fase 0) coincide com os dados da auditoria
7. Categorizar gaps em: rápido de resolver (1-2 semanas) vs. longo prazo (3-4 semanas)
8. Priorizar gaps pelo critério: maior impacto potencial no close rate

## Agentes Responsáveis
- Pattern Detector (responsável principal)
- Root Cause Analyst (suporte para causa raiz)
- Win/Loss Correlator (suporte para correlações)

## Output
- Relatório de padrões com frequência de ocorrência
- Cadeias causais documentadas para cada padrão
- Priorização de gaps por impacto potencial
- Correlações entre blocos identificadas
- Mapa de frameworks corretores para cada gap

## Critérios de Conclusão
- [ ] Padrões recorrentes identificados e documentados
- [ ] Cadeias causais completas para cada padrão
- [ ] Priorização definida
- [ ] Correlações mapeadas
- [ ] Frameworks corretores selecionados
