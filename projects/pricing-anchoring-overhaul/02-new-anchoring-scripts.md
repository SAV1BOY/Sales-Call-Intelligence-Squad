# Fase 2 — Novos Scripts de Ancoragem

> Criar novos scripts de ancoragem e value stack baseados nos frameworks de autoridade e calibrados para o produto.

## Objetivo
Produzir scripts prontos para uso que implementem o novo padrão de pricing definido no benchmark.

## Inputs
- Novo padrão de pricing definido (output da Fase 1)
- Componentes da oferta com valores individuais
- Frameworks: Value Equation, Godfather Offer, Premium Positioning
- Feedback dos closers sobre linguagem natural

## Atividades
1. Construir value stack completo do produto com valor individual de cada componente
2. Criar script de ancoragem por custo do problema ("quanto custa NÃO resolver?")
3. Criar script de ancoragem por alternativa ("quanto custaria fazer sozinho?")
4. Criar script de ancoragem por referência ("programas similares custam X")
5. Criar script de revelação de preço com instruções de tonalidade e silêncio
6. Criar script de risk reversal com garantia específica do produto
7. Adaptar scripts para os 3 contextos: casual, profissional, premium
8. Testar scripts em role-play com 3 closers e coletar feedback de naturalidade
9. Ajustar linguagem e tom com base no feedback

## Agentes Responsáveis
- Script Suggester (responsável principal)
- Rewrite Agent (suporte para naturalidade)

## Output
- Value stack documentado com valores por componente
- 3 scripts de ancoragem (custo, alternativa, referência)
- Script de revelação de preço com instruções
- Script de risk reversal
- Versões adaptadas por contexto

## Critérios de Conclusão
- [ ] Value stack completo documentado
- [ ] 3 opções de ancoragem criadas
- [ ] Script de revelação validado em role-play
- [ ] Risk reversal definido e aprovado pela empresa
- [ ] Feedback dos closers incorporado
