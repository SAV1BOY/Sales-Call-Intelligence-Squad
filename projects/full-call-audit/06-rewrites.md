# Fase 6 — Rewrites

> Reescrever os momentos-chave da call usando frameworks de autoridade, mostrando ao closer como deveria ter sido feito.

## Objetivo
Produzir de 5 a 8 reescritas de momentos críticos da call no formato antes/depois, com framework identificado e justificativa técnica.

## Inputs
- Diagnóstico de causa raiz (output da Fase 5)
- Transcrição limpa completa (output da Fase 1)
- Frameworks de correção recomendados (output da Fase 5)
- Biblioteca de frameworks do squad

## Atividades
1. Selecionar os 5-8 momentos de maior impacto para reescrita, priorizando por impacto potencial
2. Para cada momento, extrair o trecho exato da transcrição (antes)
3. Identificar o framework de autoridade mais adequado para a reescrita
4. Redigir a versão reescrita (depois) usando o framework selecionado
5. Escrever justificativa técnica explicando por que a versão reescrita é superior
6. Ajustar tom e linguagem para manter naturalidade (a reescrita deve soar como o closer, não como um robô)
7. Validar que cada reescrita passa nos 3 testes: naturalidade, framework correto, resultado provável
8. Ordenar as reescritas da mais impactante para a menos impactante

## Agentes Responsáveis
- Rewrite Agent (responsável principal)
- Script Suggester (suporte para variações de scripts)

## Output
- 5-8 reescritas completas no formato: contexto, antes, framework, depois, justificativa
- Reescritas ordenadas por impacto potencial
- Cada reescrita referencia o framework de autoridade utilizado

## Critérios de Conclusão
- [ ] Mínimo de 5 reescritas produzidas
- [ ] Todas seguem o formato padrão (contexto, antes, framework, depois, justificativa)
- [ ] Todas passam nos 3 testes de validação
- [ ] Tom adequado ao estilo do closer
- [ ] Ordenadas por impacto
