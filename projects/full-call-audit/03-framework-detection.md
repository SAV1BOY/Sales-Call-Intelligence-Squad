# Fase 3 — Detecção de Frameworks

> Identificar quais frameworks de vendas foram utilizados em cada segmento da call, com evidências textuais.

## Objetivo
Mapear todas as técnicas de vendas usadas na call com classificação de aplicação e evidências da transcrição.

## Inputs
- Call segmentada em 6 etapas (output da Fase 2)
- Biblioteca de frameworks do squad (10+ frameworks monitorados)

## Atividades
1. Para cada etapa da call, buscar evidências textuais de frameworks conhecidos
2. Classificar cada framework encontrado como: correto, parcial, incorreto ou ausente
3. Citar o trecho exato da transcrição que evidencia o uso do framework
4. Identificar frameworks que deveriam ter sido usados mas não foram
5. Mapear combinações de frameworks (ex: SPIN na discovery + Value Equation no pitch)
6. Registrar a qualidade da aplicação: o framework gerou o efeito desejado no prospect?
7. Documentar frameworks não catalogados que o closer possa ter usado

## Agentes Responsáveis
- Framework Detector (responsável principal)
- Technique Classifier (suporte para classificação correto/parcial/incorreto)

## Output
- Mapa completo de frameworks por etapa
- Evidências textuais para cada detecção
- Classificação de aplicação
- Lista de frameworks recomendados mas ausentes

## Critérios de Conclusão
- [ ] Todos os segmentos analisados
- [ ] Evidências textuais citadas para cada detecção
- [ ] Classificação de aplicação registrada
- [ ] Frameworks ausentes documentados

## Notas de Execução

- A detecção deve ser baseada em evidência textual, nunca em suposição
- Um closer pode usar um framework inconscientemente — detectar e registrar mesmo assim
- Frameworks parciais são comuns e devem ser documentados com o que faltou para ser completo
