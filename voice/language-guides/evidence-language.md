# Guia de Linguagem: Como Citar Evidência da Call

## Princípio
Toda afirmação sobre a performance de uma call deve ser sustentada por evidência específica — trecho transcrito, timestamp ou dado mensurável. Evidência sem interpretação é inútil; interpretação sem evidência é opinião. O padrão é sempre: evidência primeiro, interpretação depois.

## Formato Padrão de Citação

### Citação de Trecho com Timestamp
```
[MM:SS] "transcrição exata do trecho"
— Contexto: [o que estava acontecendo na call naquele momento]
— Observação: [o que isso significa para a análise]
```

### Exemplo Completo
```
[14:32] Prospect: "Isso está me tirando o sono. Já tentei de tudo."
[14:35] Closer: "Entendi. Bom, deixa eu te mostrar como funciona nosso programa."
— Contexto: Prospect expressou dor emocional profunda na discovery.
— Observação: O closer perdeu oportunidade de aprofundar. Pergunta ideal: "Me conta mais — o que passa pela sua cabeça de madrugada?" Isso levaria a discovery ao Nível 4.
```

## Regras de Citação

### O Que Sempre Incluir
- Timestamp exato (MM:SS) ou aproximado (aprox. 14 min)
- Transcrição literal entre aspas (sem parafrasear)
- Quem falou (closer ou prospect)
- Contexto da conversa naquele ponto
- Observação técnica sobre o que ocorreu

### O Que Nunca Fazer
- Parafrasear e apresentar como citação direta
- Citar sem timestamp — impossibilita verificação
- Interpretar intenção: ~~"o closer quis enrolar"~~ → "o closer falou por 90 segundos sem fazer pergunta"
- Citar apenas trechos negativos — incluir trechos positivos para balancear

## Formatos por Tipo de Análise

### Para Relatório de Auditoria
```
Dimensão: Discovery — Profundidade
Score: 5/10
Evidência:
  - [03:20] Closer fez 4 perguntas de situação (dentro do esperado)
  - [07:45] Primeira pergunta de problema: "Qual seu maior desafio?"
  - [08:30] Prospect revelou dor: "Estou perdendo clientes todo mês"
  - [08:35] Closer não aprofundou — passou para próxima pergunta
  - [12:00] Nenhuma pergunta de implicação foi feita
Análise: Discovery ficou no Nível 2 (problema identificado, sem implicação).
```

### Para Sessão de Coaching
```
"Tem um momento na call que quero destacar. No minuto 8:30, o prospect 
disse [transcrição]. Esse era o momento perfeito para perguntar [sugestão]. 
Vamos praticar essa abordagem?"
```

### Para Briefing Executivo
```
Dado-chave: 70% das calls analisadas têm discovery abaixo do Nível 3.
Evidência representativa: Na call de [data], a discovery durou 6 minutos 
com 0 perguntas de implicação. Padrão repetido em 7 de 10 calls.
```

## Níveis de Evidência
1. **Forte**: Transcrição exata + timestamp + padrão repetido em múltiplas calls
2. **Moderada**: Timestamp + observação + ocorrência em 2+ calls
3. **Fraca**: Observação geral sem timestamp específico (usar apenas quando áudio não está disponível)
4. **Insuficiente**: Afirmação sem qualquer evidência (não publicar)

## Erros Comuns na Citação de Evidência
- **Cherry-picking**: Selecionar apenas trechos que confirmam uma conclusão pré-definida. Solução: incluir contra-evidências também.
- **Evidência isolada**: Citar um momento ruim em uma call que foi boa no geral. Solução: contextualizar com score geral.
- **Excesso de evidência**: 15 citações quando 3 bastam. Solução: selecionar as mais representativas.
- **Evidência sem ação**: Citar o problema sem sugerir alternativa. Solução: sempre incluir "o que fazer diferente".

## Template Rápido
```
O que aconteceu: [descrição objetiva]
Quando: [timestamp]
Trecho: "[transcrição]"
Impacto: [como afetou a call]
Alternativa: [o que poderia ter sido feito]
```
