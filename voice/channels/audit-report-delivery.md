# Canal: Entrega de Relatório de Auditoria

## Princípio
O relatório de auditoria é o principal artefato de comunicação entre o Sales Call Intelligence Squad e seus stakeholders. Deve ser compreensível sem explicação verbal, acionável sem reunião adicional e justo sem contestação razoável. Um bom relatório muda comportamento; um relatório medíocre vira arquivo esquecido.

## Estrutura Padrão do Relatório

### 1. Cabeçalho (Contexto Imediato)
```
Relatório de Auditoria — [Nome do Closer]
Período: [data início] a [data fim]
Calls analisadas: [número]
Score médio: [X/100] (anterior: [Y/100])
Tendência: [subindo/estável/caindo]
```

### 2. Resumo Executivo (3-5 linhas)
- O que está funcionando bem (1-2 destaques)
- O que precisa de atenção (1-2 prioridades)
- Ação recomendada principal
- Exemplo: "O closer demonstra rapport forte e tonalidade variada. A discovery está consistentemente no Nível 2, sem atingir implicação emocional. Prioridade: treinar perguntas de implicação nas próximas 2 semanas."

### 3. Score Detalhado por Dimensão
```
| Dimensão | Score Atual | Anterior | Tendência | Benchmark |
|----------|------------|----------|-----------|-----------|
| Abertura | 7/10 | 6/10 | subindo | 7/10 |
| Rapport | 8/10 | 7/10 | subindo | 7/10 |
| Discovery | 5/10 | 5/10 | estável | 7/10 |
| Implicação | 3/10 | 3/10 | estável | 6/10 |
| Transição | 6/10 | 5/10 | subindo | 7/10 |
| Apresentação | 6/10 | 6/10 | estável | 7/10 |
| Objeção | 4/10 | 4/10 | estável | 6/10 |
| Close | 5/10 | 4/10 | subindo | 7/10 |
| Tonalidade | 7/10 | 6/10 | subindo | 7/10 |
| Talk Ratio | 5/10 | 5/10 | estável | 7/10 |
| **TOTAL** | **56/100** | **51/100** | **subindo** | **68/100** |
```

### 4. Destaques Positivos (2-3 momentos)
Para cada destaque:
- O que aconteceu (com timestamp)
- Por que é relevante
- O que manter

### 5. Áreas de Desenvolvimento (2-3 momentos)
Para cada área:
- O que foi observado (com evidência)
- O impacto no resultado
- O que fazer diferente (com reescrita quando aplicável)

### 6. Padrões Identificados
- Padrões positivos: o que está se repetindo de forma consistente e boa
- Padrões problemáticos: o que está se repetindo de forma consistente e precisa mudar

### 7. Plano de Ação
```
Prioridade #1: [dimensão] — [ação específica] — Prazo: [data]
Prioridade #2: [dimensão] — [ação específica] — Prazo: [data]
Métrica de sucesso: [como medir se melhorou]
Próxima auditoria: [data]
```

## Regras de Entrega

### Timing
- Relatório entregue em até 48 horas após a última call analisada
- Nunca entregar relatório em sexta-feira à tarde (perde impacto no fim de semana)
- Ideal: segunda ou terça-feira de manhã (semana inteira para aplicar)

### Para o Closer
- Entregar relatório + breve conversa de 10 minutos para contextualizar
- Começar com positivos, focar no plano de ação
- Perguntar: "Algo aqui não faz sentido ou não parece justo?"
- Definir próxima sessão de coaching baseada no plano de ação

### Para o Gestor
- Enviar relatório com resumo executivo destacado
- Incluir recomendação de ação do gestor (se necessária)
- Sinalizar qualquer flag vermelho (deal-breaker ou queda acentuada)
- Formato: pode ser mais resumido (só resumo executivo + score + ação)

## Tom do Relatório
- Usar tom de auditor objetivo para dados e evidências
- Usar tom construtivo para áreas de desenvolvimento
- Nunca usar linguagem punitiva ou depreciativa
- Sempre terminar com algo positivo ou com visão de futuro

## Erros Comuns na Entrega
1. **Relatório sem conversa**: Enviar PDF e sumir. O closer precisa de contexto verbal.
2. **Só negativos**: Relatório que só aponta problemas desmotiva. Incluir destaques positivos.
3. **Excesso de dimensões**: Focar em tudo = focar em nada. Máximo 2-3 prioridades.
4. **Sem plano de ação**: Diagnóstico sem prescrição = frustração.
5. **Linguagem de julgamento**: "Péssima performance" em vez de "score de 38/100 com oportunidade em [X]".

## Frequência de Relatórios
- **Semanal**: Para closers em desenvolvimento (score < 60)
- **Quinzenal**: Para closers competentes (score 60-79)
- **Mensal**: Para closers avançados/elite (score 80+)
- **Sob demanda**: Quando gestor solicita ou quando há mudança significativa
