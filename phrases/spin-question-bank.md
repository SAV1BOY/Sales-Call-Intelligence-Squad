# Banco de Perguntas SPIN

> Perguntas organizadas pelo framework SPIN Selling de Neil Rackham para diagnóstico completo.

## Fase da Call
Diagnóstico / Qualificação (5-15 minutos)

## Frases

### Situação (entender o cenário atual)

1. "Me conta, como funciona seu [processo/negócio] hoje?"
   **Quando usar**: Abertura do diagnóstico.
   **Framework**: SPIN — Situação

2. "Quantas pessoas estão envolvidas nisso hoje?"
   **Quando usar**: Para mapear stakeholders e tamanho da operação.

3. "Que ferramenta ou método vocês usam atualmente pra [resolver X]?"
   **Quando usar**: Para entender o estado atual e identificar gaps.

4. "Há quanto tempo você está nesse modelo?"
   **Quando usar**: Para entender inércia e status quo.

5. "Qual é o seu faturamento atual? E qual a meta?"
   **Quando usar**: Para dimensionar o gap entre realidade e objetivo.

### Problema (identificar dores)

6. "Qual o maior desafio que você enfrenta hoje com [área]?"
   **Quando usar**: Para abrir a dor principal.
   **Framework**: SPIN — Problema

7. "O que te incomoda mais nesse processo atual?"
   **Quando usar**: Para aprofundar insatisfação.

8. "Você está satisfeito com os resultados que está tendo?"
   **Quando usar**: Pergunta fechada para forçar reflexão.

9. "Se pudesse mudar uma coisa no seu [negócio/processo], o que seria?"
   **Quando usar**: Para priorizar a dor mais urgente.

10. "Já tentou resolver isso antes? O que aconteceu?"
    **Quando usar**: Para entender tentativas frustradas.

### Implicação (amplificar a dor)

11. "E quando isso acontece, qual o impacto no seu faturamento?"
    **Quando usar**: Para conectar problema a dinheiro.
    **Framework**: SPIN — Implicação

12. "Se nada mudar nos próximos 6 meses, onde você vai estar?"
    **Quando usar**: Para criar urgência com projeção futura.

13. "Isso afeta só você ou a equipe inteira sente?"
    **Quando usar**: Para ampliar o escopo do problema.

14. "Quanto tempo por semana você perde lidando com isso?"
    **Quando usar**: Para quantificar custo de oportunidade.

15. "Esse problema já te fez perder algum cliente ou oportunidade?"
    **Quando usar**: Para gerar dor concreta.

### Need-Payoff (fazer o lead visualizar a solução)

16. "Se você resolvesse isso, o que mudaria no seu dia a dia?"
    **Quando usar**: Para criar visão de futuro positivo.
    **Framework**: SPIN — Need-Payoff

17. "Quanto valeria pra você ter [resultado desejado]?"
    **Quando usar**: Para ancorar valor antes do preço.

18. "Se existisse uma forma de [resolver dor] sem [objeção comum], faria sentido pra você?"
    **Quando usar**: Para criar abertura mental para a solução.

19. "Imagina que daqui 90 dias isso estivesse resolvido. O que seria diferente?"
    **Quando usar**: Para ativar visualização emocional.

20. "Se a gente pudesse te entregar [resultado], quanto isso impactaria no seu resultado?"
    **Quando usar**: Para o lead verbalizar o valor por conta própria.

## Frases a Evitar
- "Qual seu orçamento?" — **Por quê**: Muito cedo. Descubra a dor antes de falar de dinheiro.
- "Você conhece nosso produto?" — **Por quê**: Foco deve ser no lead, não em você.
- "Posso te falar sobre a gente?" — **Por quê**: Ainda não é hora. Diagnóstico primeiro.
