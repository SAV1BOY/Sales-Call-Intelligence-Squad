# Frases para Objeção de Tempo

> Frases para lidar com "agora não é o momento", "estou muito ocupado" e "vamos deixar pra depois".

## Fase da Call
Tratamento de Objeções — Tempo (25-35 minutos)

## Frases

### Entender a Objeção

1. "Entendo que o momento é corrido. Quando seria o momento certo pra você?"
   **Quando usar**: Para testar se é objeção real ou cortina de fumaça.
   **Framework**: Sandler — Time Objection Test

2. "Faz sentido. Me ajuda a entender: é falta de tempo pra decidir ou pra implementar?"
   **Quando usar**: Para separar tempo de decisão de tempo de execução.
   **Framework**: Diagnóstico de Objeção

3. "E daqui a 3 meses, a situação de tempo vai estar diferente?"
   **Quando usar**: Para mostrar que esperar não resolve a falta de tempo.

4. "Se eu te dissesse que demora só [tempo mínimo] por semana, mudaria sua perspectiva?"
   **Quando usar**: Para redimensionar o compromisso de tempo.

### Urgência pela Inação

5. "Entendo. Mas o problema que você me contou vai esperar?"
   **Quando usar**: Para reconectar com a dor diagnosticada.
   **Framework**: NEPQ — Consequence Reconnection

6. "Cada semana que passa sem resolver, você perde [valor]. Em 3 meses são [valor x 12]."
   **Quando usar**: Para quantificar custo da espera.
   **Framework**: Custo de Oportunidade

7. "A maioria das pessoas que dizem 'depois' nunca fazem. Você é diferente?"
   **Quando usar**: Para provocar com elegância. Use com cuidado.
   **Framework**: Challenge Selling

8. "Quando é o momento certo pra parar de perder dinheiro?"
   **Quando usar**: Para criar desconforto com a procrastinação.

### Facilitação

9. "E se a gente estruturasse tudo pra você ter o mínimo de trabalho? O que acha?"
   **Quando usar**: Para remover a objeção de esforço.
   **Framework**: Done-For-You Selling

10. "A implementação leva [X] horas no total. Dá pra encaixar em qualquer rotina."
    **Quando usar**: Para tangibilizar o tempo necessário.

11. "Nossos clientes mais ocupados são os que mais precisam. Eles não têm tempo de perder com o que não funciona."
    **Quando usar**: Para reframing de ocupado para urgente.

12. "Começar agora não significa fazer tudo agora. Significa garantir sua vaga e a condição."
    **Quando usar**: Para separar decisão de ação.
    **Framework**: Commitment vs Action Split

### Futuro

13. "Imagina daqui 6 meses: você pode ter resolvido isso ou estar no mesmo lugar. Qual cenário prefere?"
    **Quando usar**: Para criar contraste futuro.
    **Framework**: Future Pacing

14. "O melhor momento era ontem. O segundo melhor é hoje."
    **Quando usar**: Como frase de impacto para fechar a objeção de tempo.

## Frases a Evitar
- "Entendo, liga quando puder" — **Por quê**: Perdeu a venda. Lead nunca vai ligar.
- "Sem problema, fica pra próxima" — **Por quê**: Não existe próxima. A call é agora.
- "Tá bom, te mando um e-mail" — **Por quê**: E-mail é onde vendas vão morrer.
