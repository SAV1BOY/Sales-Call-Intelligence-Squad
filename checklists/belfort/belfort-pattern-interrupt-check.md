# Checklist de Pattern Interrupt — Jordan Belfort

> Avaliar se interrupções de padrão foram usadas para recapturar atenção quando necessário.

## Framework de Referência
Pattern Interrupt — Jordan Belfort (Straight Line Persuasion)

## Checklist

### Identificação da Necessidade
- [ ] O closer percebeu quando o lead perdeu atenção ou engajamento
- [ ] Sinais de desinteresse foram detectados (respostas curtas, silêncio)
- [ ] O closer identificou quando a conversa caiu em padrão previsível
- [ ] Momentos de energia baixa foram reconhecidos rapidamente
- [ ] O closer não ignorou sinais de desengajamento do lead

### Execução do Pattern Interrupt
- [ ] A interrupção de padrão foi inesperada mas apropriada
- [ ] O closer usou mudança de tom, ritmo ou assunto para surpreender
- [ ] A interrupção recapturou a atenção do lead efetivamente
- [ ] O lead demonstrou re-engajamento após o pattern interrupt
- [ ] A técnica foi sutil, não agressiva ou estranha

### Tipos de Pattern Interrupt Utilizados
- [ ] Mudança abrupta de tom (de sério para leve, ou vice-versa)
- [ ] Pergunta inesperada que quebra o fluxo previsível
- [ ] História curta ou anedota relevante inserida no momento certo
- [ ] Humor apropriado para quebrar tensão ou monotonia
- [ ] Pausa estratégica seguida de mudança de direção

### Resultado do Pattern Interrupt
- [ ] O lead se re-engajou após a interrupção de padrão
- [ ] A conversa ganhou nova energia após o interrupt
- [ ] O rapport não foi prejudicado pela interrupção
- [ ] A linha reta foi retomada após recuperar a atenção
- [ ] O lead demonstrou interesse renovado na conversa

## Critérios de Aprovação
- **Aprovado**: Pattern interrupts usados quando necessário; re-engajamento obtido
- **Parcial**: Pattern interrupt tentado mas com eficácia limitada
- **Reprovado**: Nenhum pattern interrupt quando necessário; ou uso excessivo/inadequado

## Evidência Requerida
- Timestamps dos momentos de desengajamento do lead
- Trechos da transcrição mostrando o pattern interrupt executado
- Evidência de re-engajamento do lead após a interrupção
- Tipo de pattern interrupt utilizado em cada instância

## Erros Comuns
1. Não perceber que o lead perdeu interesse e continuar no mesmo ritmo
2. Usar pattern interrupt de forma exagerada ou desconfortável
3. Usar humor inadequado como pattern interrupt
4. Não retomar a linha reta após o pattern interrupt
5. Confundir pattern interrupt com interrupção rude da fala do lead
