# Cross-Squad Handoff Quality

> Valida a qualidade dos insights repassados para squads de copy, traffic, offer e ops.

## Objetivo

Garantir que os insights extraidos das calls sao acionaveis para times de copy, trafego, oferta e operacoes, com contexto e prioridade.

## Quando Usar

Apos a consolidacao de insights de um lote de calls e antes de enviar para outros squads.

## Checklist

### Insights para Copy
- [ ] Palavras e expressoes exatas do lead catalogadas para uso em copy
- [ ] Objecoes mais frequentes listadas para tratamento preventivo em copy
- [ ] Dores verbalizadas pelo lead transcritas literalmente
- [ ] Beneficios que mais ressoaram com os leads identificados
- [ ] Linguagem que gerou resistencia sinalizada para evitar

### Insights para Traffic
- [ ] Perfil dos leads mais qualificados descrito para segmentacao
- [ ] Perfil dos leads desqualificados descrito para exclusao
- [ ] Canal de origem correlacionado com qualidade do lead
- [ ] Custo por lead qualificado vs desqualificado estimado
- [ ] Recomendacoes de ajuste de segmentacao emitidas

### Insights para Offer
- [ ] Gaps entre o que o lead precisa e o que a oferta entrega identificados
- [ ] Features mais valorizadas pelos leads ranqueadas
- [ ] Features irrelevantes ou confusas sinalizadas
- [ ] Sugestoes de ajuste de oferta baseadas em feedback real
- [ ] Objecoes que indicam problema de oferta (nao do closer) separadas

### Insights para Ops
- [ ] Problemas de processo identificados (agendamento, follow-up, CRM)
- [ ] Gargalos de handoff sinalizados
- [ ] Sugestoes de automacao ou melhoria operacional
- [ ] Metricas operacionais impactadas por problemas de call

### Formato e Acionabilidade
- [ ] Cada insight tem acao sugerida clara
- [ ] Insights priorizados por impacto (alto, medio, baixo)
- [ ] Frequencia do insight declarada (quantas calls evidenciam)
- [ ] Destinatario de cada insight identificado (qual squad, qual pessoa)

## Criterios de Aprovacao

- **Aprovado**: Insights para 4 squads com acoes, prioridade e frequencia declarada
- **Revisao necessaria**: Insights sem acao sugerida ou sem prioridade
- **Reprovado**: Insights genericos sem evidencia de calls ou sem destinatario

## Evidencia Requerida

Lista de insights por squad com trecho de call, frequencia, prioridade, acao sugerida e destinatario.

## Agente Responsavel

Cross-Squad Handoff Agent
