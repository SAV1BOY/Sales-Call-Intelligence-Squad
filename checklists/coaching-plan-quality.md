# Coaching Plan Quality

> Valida a qualidade do plano de coaching gerado para o closer.

## Objetivo

Garantir que o coaching plan tem acoes praticas, top 3 prioridades claras, exercicios especificos e metricas de progresso mensuraveis.

## Quando Usar

Apos a geracao do coaching plan e antes de entregar ao gestor e ao closer.

## Checklist

### Acoes Praticas
- [ ] Cada acao e especifica e executavel (nao vaga como "melhorar discovery")
- [ ] Acoes tem verbo de acao claro (praticar, gravar, revisar, aplicar)
- [ ] Cada acao tem prazo sugerido de implementacao
- [ ] Acoes estao conectadas diretamente aos gaps identificados na auditoria
- [ ] Maximo de 7 acoes para nao sobrecarregar o closer

### Top 3 Prioridades
- [ ] As 3 prioridades mais criticas estao destacadas e ordenadas
- [ ] Prioridade 1 e a que mais impacta o resultado de vendas
- [ ] Cada prioridade tem justificativa baseada em evidencia da call
- [ ] Prioridades sao atingiveis no curto prazo (1-2 semanas)

### Exercicios Especificos
- [ ] Minimo de 2 exercicios praticos por prioridade
- [ ] Exercicios tem instrucoes claras passo a passo
- [ ] Exercicios incluem role-play com cenario especifico
- [ ] Exercicios tem criterio de sucesso definido
- [ ] Scripts de referencia fornecidos quando aplicavel

### Metricas de Progresso
- [ ] Cada prioridade tem metrica mensuravel de progresso
- [ ] Metricas sao observaveis na proxima call auditada
- [ ] Baseline atual declarado (onde o closer esta hoje)
- [ ] Meta declarada (onde precisa chegar)
- [ ] Prazo para reavaliacao definido

### Personalizacao
- [ ] Plano considera o nivel de maturidade do closer
- [ ] Plano referencia calls anteriores quando ha historico
- [ ] Linguagem do plano e motivacional sem ser condescendente
- [ ] Pontos fortes do closer reconhecidos antes dos gaps

## Criterios de Aprovacao

- **Aprovado**: Top 3 com exercicios, metricas claras, acoes praticas e personalizadas
- **Revisao necessaria**: Acoes vagas ou metricas nao mensuraveis
- **Reprovado**: Plano generico sem conexao com a auditoria ou sem exercicios

## Evidencia Requerida

Top 3 prioridades com justificativa da auditoria, exercicios detalhados, metricas com baseline e meta, e prazo de reavaliacao.

## Agente Responsavel

Coaching Plan Agent

## Scoring Rubric

Cada item acima deve ser pontuado de 0 a 5:

| Score | Significado |
|-------|------------|
| 0 | Ausente — item nao abordado |
| 1 | Mencionado sem evidencia |
| 2 | Presente com evidencia fraca ou generica |
| 3 | Presente com evidencia especifica (trecho + timestamp) |
| 4 | Forte — evidencia + analise + recomendacao |
| 5 | Exemplar — material para swipe file |

### Thresholds
- **Pass minimo**: media >= 3.0 (todos os items)
- **GOOD**: media >= 3.5
- **GOLD**: media >= 4.5
- **Rework trigger**: qualquer item com score 0 OU media < 2.5
- **Aprovacao**: QA Guardian valida; Sales Chief aprova output final
