# Checklist de Empilhamento de Valor — Sabri Suby

> Avaliar se o valor foi empilhado antes do preço, com valor total muito superior ao preço.

## Framework de Referência
Value Stack — Sabri Suby (Sell Like Crazy)

## Checklist

### Empilhamento Antes do Preço
- [ ] Todos os componentes de valor foram apresentados ANTES do preço
- [ ] Cada componente teve seu valor individual mencionado
- [ ] O acúmulo de valor foi progressivo e impactante
- [ ] O closer fez pausas para o lead absorver cada camada de valor
- [ ] O preço foi revelado somente após completar o empilhamento

### Valor Total >> Preço
- [ ] O valor total empilhado é pelo menos 5-10x o preço pedido
- [ ] O closer verbalizou o valor total antes de mencionar o preço
- [ ] O contraste valor total vs preço gerou reação positiva no lead
- [ ] O lead percebeu que está pagando fração do valor real
- [ ] A relação valor/preço foi explicitamente demonstrada

### Componentes do Value Stack
- [ ] Produto/serviço principal com valor atribuído
- [ ] Bônus #1 com valor individual e benefício claro
- [ ] Bônus #2 com valor individual e benefício claro
- [ ] Bônus #3 (se aplicável) com valor individual
- [ ] Garantia como componente de valor adicional
- [ ] Acesso, suporte ou comunidade como valor extra

### Apresentação do Stack
- [ ] Cada componente foi apresentado como produto independente
- [ ] O closer explicou o benefício específico de cada componente
- [ ] O lead demonstrou interesse em cada componente individualmente
- [ ] O acúmulo visual/verbal de valor foi claro
- [ ] O "total" foi mencionado antes do preço real

## Critérios de Aprovação
- **Aprovado**: Stack completo antes do preço; valor total 5x+ preço; lead impressionado
- **Parcial**: Stack parcial; valor total 2-3x preço; reação moderada
- **Reprovado**: Sem stack; preço sem contexto de valor; lead indiferente

## Evidência Requerida
- Lista de todos os componentes do stack com valores atribuídos
- Valor total empilhado vs preço pedido
- Timestamp de cada componente apresentado
- Reação do lead ao acúmulo de valor e ao preço final

## Erros Comuns
1. Não atribuir valor monetário individual a cada componente
2. Revelar preço antes de completar o empilhamento
3. Componentes fracos que não agregam valor percebido
4. Apresentar tudo de uma vez sem pausas para absorção
5. Não fazer o contraste explícito entre valor total e preço
